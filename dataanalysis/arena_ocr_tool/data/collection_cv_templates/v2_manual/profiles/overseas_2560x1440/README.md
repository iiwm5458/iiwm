# Overseas 2560x1440 Collection Profile

This profile is isolated to overseas/HMT source files named `2560x1440`.
It uses the wide overseas collection grid with a measured crop phase of
`x=+1`, `y=-2` pixels.  It reuses the reviewed manual positive templates in
the parent library, deliberately omits generic empty-slot templates, and
therefore cannot inherit the false-empty veto observed on this export.  The
contact sheet is a review aid built from the aligned HMT group64 export; it is
not part of runtime matching.  No CN profile and no existing overseas FHD or
3440x1440 template selection reads this directory.

# Collection CV Templates v2 Manual

This template library is built only from manually prepared Photoshop cutouts in `manual_annotations`.

Labels: `R`, `R15`, `SR`, `SR15`, `SSR`, `SSR3`, and `none`.

`position_calibration.json` is generated from the manual red-hex position maps. The PS-resized annotation images are mapped back to original exported screenshots by the measured/manual scale factors.

Legacy workbook labels named `SSR15` should be treated as `SSR3`; `R15` remains an independent level.

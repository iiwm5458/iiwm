# NIKKE OCR 左侧四 Block 标注工具

打开 `index.html` 即可使用。这是原“整张大图标注工具”的独立副本：原工具和当前 OCR 运行逻辑均不会被它修改。

## 工作范围

- 选择一张完整的 `64进32全部战斗数据（详）` 大图后，画布只显示最左侧纵向 4 个样本 block：`G1M1`、`G1M3`、`G5M1`、`G5M3`。
- 坐标始终使用完整大图的原始坐标系；导出的 JSON 仅包含这 4 个 block 的数据，便于后续反推至整图。
- 工具保留所有现有类别：对局 block、阵容/赛果面板、玩家昵称/ID、阵容整行、妮姬名字、妮姬战力、藏品图标、循环等级、赛果页名字、战败贴图。
- 赛果页名字是“每轮、每侧、每位妮姬”独立框。要缩紧赛果页妮姬名时，请在“赛果页名字”类别中逐格调整，不要把它改回大范围整行框。

## 建议操作顺序

1. 选择对应服务器与分辨率，点击“更替当前分辨率底图”，选择完整大图。
2. 确认画布依次显示 `G1M1`、`G1M3`、`G5M1`、`G5M3`；先用红色“对局 block”框确认纵向位置和间距。
3. 切换“赛果页名字”，把每个名字框收紧到实际文字。不需要调的其它元素可以保持默认值；需要顺手校准的元素也可直接修改。
4. “联动当前 block 的赛果页 5 行”默认开启：调整第 1 轮同名位置时，后 4 轮会同步移动/缩放。若四个样本 block 的局部几何一致，再自行勾选“同名识别框跨 4 个样本 block 联动”。
5. 用 `S` 锁定确认过的框；`[` 和 `]` 在当前类别的未锁定框间切换；`Ctrl+Z` 撤销。
6. 点击“保存四 Block JSON”，把导出的 JSON 发回当前项目对话。不要将此 JSON 直接导入 GUI 或直接投入 OCR。

## 联动与间距

- `GROUP 间距 / 对局横距 / 对局纵距`：按 64进32 的拼图规则重新计算 block 位置；工具只显示 4 个样本，但保存完整原图坐标。
- “block 移动/缩放跨样本联动”：仅会联动当前可见的四个样本 block，不会改动未展示的其余 block。
- “同名识别框跨 4 个样本 block 联动”：仅联动当前可见的四个样本，不会预先把标注写到整张图。
- “联动当前 block 的阵容页 5 行”和两项藏品联动保留原行为，可用于其它元素的校准。

## 快捷键

- 方向键：移动选中框 1px。
- `Shift + 方向键`：移动选中框 10px。
- `S`：锁定或解锁当前框；锁定后自动跳到当前类别的下一未锁定框。
- `[` / `]`：切换当前类别的上一/下一未锁定框。
- `C`：进入藏品标注模式。
- `Delete`：删除未锁定的选中框。
- `Ctrl+Z`：撤销上一步。

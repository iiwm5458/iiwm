# Manual Click Prompt Sounds

`prompt_musicbox.wav` is a short, trimmed derivative of the **UI Sound Effects
(Button Clicks, User Feedback, Notifications)** pack by Robin Lamb at
OpenGameArt.

- Source: https://opengameart.org/content/ui-sound-effects-button-clicks-user-feedback-notifications
- Original file: `Ding.wav`
- License: CC0 1.0 Universal (Public Domain Dedication)
- Downloaded: 2026-09-19

The source pack expressly permits copying, modifying, and redistributing the
file. The bundled version has only been shortened and faded for use as a brief
manual-click prompt.

## 1. 项目目标

本项目是一个用于《胜利女神：新的希望 / NIKKE》冠军竞技场（C ARENA）的自动截图、拼图、战后数据识别工具。

核心能力包括：

1. 自动切换到 NIKKE 游戏窗口。
2. 自动点击玩家头像、页签、GROUP、战果按钮、详细战斗数据按钮。
3. 自动截图并按用户指定样式拼接：
   - 单人阵容长图
   - 应援双方阵容图
   - 晋级赛 GROUP 阵容图
   - 晋级赛 64/32/16 强战斗数据图
   - TOP8 冠军争霸赛战斗数据图
   - 赛季全部战斗数据一键采集图
4. 将截图叠加到底图背景板上输出。
5. OCR 识别战斗数据图像，导出 JSON 和 Excel，用于后续数据分析。
6. GUI 交互窗口支持暗色/月亮主题、粉白主题、截图参数设置、手动上传战斗数据图像识别、妮姬名单维护等功能。

## 5. 已实现或部分实现的核心流程

### 5.1 单人阵容截图

入口：`C ARENA单人阵容截图`

用户先打开竞技场信息页面，再点击二级页面中的执行截图按钮。

流程大致为：

1. 自动切换到 NIKKE 窗口。
2. 点击当前竞技场信息中的玩家头像。
3. 进入玩家资料卡。
4. 截取用户基础信息。
5. 切换前哨基地页签。
6. 截取同步等级、研究等级小卡、队伍属性、部队战斗力等信息。
7. 返回竞技场信息页。
8. 依次截取 Round 01 到 Round 05 的阵容卡片区域。
9. 拼接为长图。

重要裁剪要求：

1. 用户基础信息两边黑边要裁掉，使边缘宽度和下方阵容区域一致。
2. 阵容区域不包含 Round 页签 UI，边缘不要过多留白。
3. 队伍战斗力区域两边不能有黑边。

### 5.2 应援双方阵容截图

入口：`应援双方阵容截图`

流程：

1. 用户打开应援信息界面。
2. 点击左侧玩家头像。
3. 对左侧玩家执行单人阵容截图逻辑，但不单独导出。
4. 按两次 Esc 回到应援页面。
5. 点击右侧玩家头像。
6. 对右侧玩家执行单人阵容截图逻辑，但不单独导出。
7. 左右两栏拼接。
8. 可选 `应援现状`，将支持率对比条拼接到底部。

应援现状截图需要包含左右百分比和中间对比条，两边留白要稍多一些。

### 5.3 晋级赛 GROUP 阵容截图

入口：`C ARENA 晋级赛 GROUP阵容截图`

二级页面按钮：

1. `执行64强该组8人截图`
2. `执行32强该组4人截图`
3. `执行16强该组双人截图`

复选项：

1. 背景板底图：`玛丽安` / `Doro` / `灰姑娘` / `自定义`
2. 战后数据：
   - `赛后数据（简化）`
   - `赛后数据（详细）`
3. `我要所有GROUP的数据`
4. `同时导出json数据块和excel数据` 当前应禁用，详见后续待办。

64 强该组 8 人逻辑：

1. 点击本组 8 个玩家头像。
2. 对每人执行单人阵容截图逻辑，但不单独导出。
3. 若未勾选战后数据，按 2 行 4 列拼接。
4. 若勾选战后数据（简化），点击 4 个蓝色战果按钮，截取简化战果区域，插入对应两名玩家中间。
5. 若勾选战后数据（详细），点击 4 个蓝色战果按钮，再依次点击每个战果页面中的 5 个黑色按钮，截取详细战斗数据，拼接后插入对应两名玩家中间。

32 强该组 4 人逻辑：

1. 点击 4 个玩家头像。
2. 不勾选战后数据时单行从左至右排列。
3. 勾选战后数据时点击 2 个战果按钮。
4. 如果战果页底部出现 `16强` / `32强` 页签，需要识别并点击 `32强` 页签。
5. 如果没有这两个页签，不允许乱点空白，否则页面会关闭；应直接按 64 强战果页逻辑截取当前页。
6. 简化/详细逻辑与 64 强一致，只是战果按钮数量不同。

16 强该组双人逻辑：

1. 点击 2 个玩家头像。
2. 不勾选战后数据时两栏拼接。
3. 勾选战后数据时，需要识别两个战果按钮哪个是紫色，点击紫色按钮，不能点击灰色按钮。
4. 进入战果页后默认是 16 强页，后续套用 32 强战果页逻辑，不需要再点击页签。

`我要所有GROUP的数据`：

1. 自动依次点击 GROUP01 到 GROUP08。
2. 每组执行对应模式。
3. 最终按 GROUP 顺序拼接：
   - 64/32 强通常为 2 行 4 列。
   - 16 强如果用户要求，可以横向排列。
4. GROUP 与 GROUP 之间的间距需要稍大，GROUP 内部阵容间距保持原来的。

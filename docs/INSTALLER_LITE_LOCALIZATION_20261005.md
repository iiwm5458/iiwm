# 安装目录与轻量版多语言更新记录（2026-10-05）

## 更新原因

- 用户反馈默认安装到 AppData 后出现识图异常，要求两版新安装默认使用 C 盘固定父目录，并保留现有产品文件夹名称。
- 轻量版部分独立弹窗和动态提示未接入翻译资源，切换语言后音量设置、帮助正文等仍显示中文；较长的翻译也需要换行和按钮宽度适配。

## 本次修改

- 完整版默认安装目录：`C:\NIKKE_C_ARENA_Tool\NIKKE C ARENA Tool`。
- 轻量版默认安装目录：`C:\NIKKE_C_ARENA_Tool\NIKKE C ARENA 截图工具 轻量版`。
- 保持两版原 AppId 和每用户安装模式；显式设置 `UsePreviousAppDir=no`、`DisableDirPage=no`。每次普通启动安装器都默认显示上述 C 盘目录，用户可自行选择其它目录；旧安装记录不会恢复为默认路径。
- 安装目录页只读检查两版混装；复制程序前再次检查版本和可写性。写检查只清理自身临时文件及空目录，不自动提权、修改权限、删除旧目录或迁移用户数据。
- 轻量版补充英语、日语、韩语的音量设置、帮助全文、按钮、工具提示及动态消息；格式模板先翻译，再填入数值、文件路径和异常原文。
- 音量、帮助弹窗改为可独立构造后显示，补充自动换行和按钮宽度适配，修复音量百分比布局。音色配置值仍为 `8bit` / `musicbox_chime`。
- 修复多行翻译资源的 CRLF / LF 匹配差异，避免帮助正文回退为中文。

本次不增加致谢名单、不改变轻量版 OCR 展示功能或截图业务参数、不修改完整版界面。官方安装器仍不携带私有罗技 MOD 或用户 GPU 运行环境，原地覆盖升级不会删除未列入安装载荷的 `mods`、`runtime_gpu`。

## 默认路径策略修正

用户补充说明：部分用户会直接删除程序文件夹，系统中的旧安装记录可能仍然存在，因此旧用户升级或重新安装时，也不应默认恢复历史路径。

据此将两版 `UsePreviousAppDir` 由 `yes` 改为 `no`。目录选择页继续显示，保留用户手动选回原目录进行覆盖更新的能力；选择新目录不会自动搬移旧配置、MOD、GPU 环境，也不会删除旧文件夹。没有清理真实卸载登记或更换产品 AppId。

修正后两份完整安装脚本编译通过，目录检查测试 28 项再次通过。新增 `tools/test_installer_default_directory.ps1`，14 项原生行为检查和 6 项生产设置检查全部通过：用 `yes` 对照确认有效的历史记录在旧文件夹存在或被删除后都会恢复历史路径，而 `no` 会使用新的 C 盘默认路径；无旧记录时默认正确，显式自选目录仍生效。

默认路径测试使用两个随机 AppId 的临时 HKCU 测试记录，测试安装器在 `InitializeWizard` 记录实际路径后立即中止，没有安装产品；临时测试记录已全部清理，真实产品记录未改动。报告位于 `work/installer_default_directory_ad540be899a1488490128e5ec55b4aed`。该默认路径修正没有更改轻量版多语言源码；D 盘已安装程序五个关键文件的 SHA256 仍匹配修改前记录。

## 语言按钮误译修正

用户发现轻量版切换为英语或韩语后，简体中文按钮“中”显示为截断的 `Medium` 或 `중간`。原因是“中”同时用作战果标记的中等字号资源键：翻译函数仅跳过语言按钮本身，视觉树遍历仍进入其模板内部的无名 `TextBlock`，误用了字号翻译。

逻辑树和视觉树遍历现在都跳过语言按钮的整个子树；更新语言按钮状态时固定使用原生标识 `中 / 日 / EN / 한`，工具提示保持 `简体中文 / 日本語 / English / 한국어`。保留中等字号选项的正常翻译，避免通过修改公共“中”资源影响其它功能。

修正前备份：`backups/lite_language_glyph_20261005_023834`。轻量版最新脚本在隔离目录执行 `-Check` 通过，PowerShell 语法、UTF-8 BOM 和差异格式检查通过。

`tools/test_lite_localization.ps1` 新增真实按钮模板回归，使用生产 `LanguageGlyphButton` 样式构造并布局 `ContentPresenter` / `TextBlock`。修复前快照明确复现英语下 `LanguageZhButton` 实际显示 `Medium`；修复后全部 523 项检查通过（原 392 项及新增 131 项）。覆盖四语言往返和暗色/粉色主题，检查实际呈现的文字和工具提示，并验证同一控件树中的普通中等字号选项仍译为 `Medium` / `중간`。

修复前后离屏图片及实际显示文字记录位于 `work/lite_language_button_regression_6c2d9fa5c5ad4c6db3eeabd7fabb7084`。该源码修正阶段没有运行可见或模态窗口，没有修改原用户配置和 D 盘已安装程序，也没有封装或上传。

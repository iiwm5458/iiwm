# 完整版输入 MOD 兼容与封装约定

从完整版 0.1.23 开始，截图程序提供 API v1 的鼠标按键扩展入口。该入口只随完整版安装；轻量版不复制 `nikke_input_plugins.py`，也不提供设置项。光标坐标及移动继续由原截图程序负责，扩展只负责左键按下和抬起。

当前宿主只接受项目核准的 `logitech_click` MOD。加载前先核对其固定目录、ID、API 版本、清单和后端文件 SHA-256；未通过校验的文件不得导入或显示为可选项。校验是正式入口的准入限制，不代替 Windows 对本地安装目录的权限保护。

MOD 文件安装到 `%LOCALAPPDATA%\NIKKE C ARENA Tool\mods\logitech_click`，独立于完整版程序目录 `%LOCALAPPDATA%\Programs\NIKKE C ARENA Tool`。完整版安装器和跨历史版本补丁只包含通用宿主文件，不包含 MOD、G HUB 或第三方驱动；补丁不删除 MOD 目录，也不覆盖用户的 `nikke_round_config.json`。安装器首次安装时才创建默认配置。

后续正式版保持 API v1 与现有核准 MOD 的文件哈希可用，不应因替换 GUI 或截图程序而使已安装 MOD 失效。如需变更接口或核准新的 MOD 文件，先审查、更新宿主校验值，再测试旧 MOD 的兼容性；不能静默加载任意第三方 Python 文件。MOD 的新版本仍必须单独封装和发布，不进入正式版安装包或升级补丁。

发布前至少验证以下路径：

1. 无 MOD 的完整版沿用原有点击方式，设置页无 MOD 选项。
2. 原版 MOD 的清单与后端文件通过宿主校验，设置页显示选项和风险提示；截图前通过同一截图 worker 预检。
3. 修改清单或后端任意字节、增加其它 Python 后端、使用其它 ID，宿主均拒绝加载。
4. 轻量版发行目录不存在宿主文件和 MOD 设置。
5. 在安装了 MOD 且已保存选择的完整版目录上覆盖正式版补丁，MOD 文件及配置保留，并继续通过宿主校验。

对应的公开源码回归测试为 `python -m unittest tools.test_input_plugin_host tools.test_detailed_capture_flow`；生成正式版补丁后运行 `tools/test_full_history_update.ps1 -PatchRoot <补丁目录>` 验证实际历史版本覆盖流程。测试只写入 `dist` 下的新隔离目录。

独立 MOD 本体、专用安装/构建工具及独立罗技点击测试项目不进入本源码仓库，也不进入正式安装包或补丁。公开宿主测试使用不访问设备的临时模拟载荷，模拟哈希只修改测试实例，生产白名单保持不变。维护者本地有私有 MOD 时，额外验证真实载荷的固定哈希与覆盖更新兼容性；缺失私有载荷时公开构建仍可完成，真实载荷校验会明确跳过。
